# Виджет банковских операций
## Данный виджет разработан для удобства пользования клиентами банка и содержит следующие функции:
### 1.`get_mask_card_number` - функция, возвращающая маску номера карты клиента, например:
- входные данные: 7000792289606361
- выходные данные: 7000 79** **** 6361
### 2. `get_mask_account` - функция, возвращающая маску номера счета клиента, например:
- входные данные: 73654108430135874305
- выходные данные: **4305
### 3. `mask_account_card` - функция маскировки номеров карт и номеров счетов, например:
#### Пример для карты
- входные данные: Visa Platinum 7000792289606361  
- выходные данные: Visa Platinum 7000 79** **** 6361  

#### Пример для счета
- входные данные: Счет 73654108430135874305
- выходные данные: Счет **4305
### 4. `get_date` - функция, изменяющая формат даты, например:
- входные данные: 2024-03-11T02:26:18.671407
- выходные данные: 11.03.2024
### 5. `filter_by_state` - функция возвращает новый список словарей, содержащий только те словари, у которых ключ state (по умолчанию 'EXECUTED') соответствует указанному значению, например:
- выходные данные: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
### 6. `sort_by_date` - функция возвращает новый список словарей, отсортированных по дате (по умолчанию — убывание), например:
- выходные данные: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
